# Auxiliar function for the Ex-Wald distribution

This function is an auxiliar function.

## Usage

``` r
uandv(
  x,
  y,
  firstblock = 20,
  block = 0,
  tol = .Machine$double.eps^(2/3),
  maxseries = 20
)
```

## Arguments

- x:

  a value for x.

- y:

  a value for y.

- block:

  a value.

- tol:

  is the tolerance.

- maxseries:

  maximum value for series.

## Value

returns a vector with starting values.
