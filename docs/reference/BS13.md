# The Birnbaum-Saunders family - Santos-Neto et al. (2012) (P11 Based on the fourth Tweedie)

The function `BS13()` defines the Birnbaum-Saunders distribution, a
two-parameter distribution, for a `gamlss.family` object to be used in
GAMLSS fitting using the function
[`gamlss()`](https://rdrr.io/pkg/gamlss/man/gamlss.html).

## Usage

``` r
BS13(mu.link = "log", sigma.link = "log")
```

## Arguments

- mu.link:

  defines the mu.link, with "log" link as the default for the mu
  parameter (representing the scale \\\omega\\).

- sigma.link:

  defines the sigma.link, with "log" link as the default for the sigma
  parameter (representing the shape \\\psi\\).

## Value

Returns a `gamlss.family` object which can be used to fit a BS13
distribution in the
[`gamlss()`](https://rdrr.io/pkg/gamlss/man/gamlss.html) function.

## Details

The Birnbaum-Saunders distribution with parameters `mu` and `sigma`
(where `mu` represents \\\omega\\ and `sigma` represents \\\psi\\) has
density given by

\\f(x\|\mu,\sigma) = \frac{1}{\sqrt{2\pi}} \exp\left( -\frac{\sigma}{2}
\left\[ \frac{x\sigma}{\mu} + \frac{\mu}{x\sigma} - 2 \right\] \right)
\frac{\[x\sigma + \mu\]}{2\sqrt{\mu x^3}}\\

for \\x\>0\\, \\\mu\>0\\ and \\\sigma\>0\\. In this parameterization,
\\E(X) = \frac{\mu}{\sigma} + \frac{\mu}{2\sigma^2}\\ and \\Var(X) =
\frac{\mu^2}{\sigma^3} + \frac{5\mu^2}{4\sigma^4}\\.

gendat <- function(n) {
  x1 <- runif(n)
  x2 <- runif(n)
  mu <- exp(1.1 + 1.1 * x1)      # Aprox 5
  sigma <- exp(2.2 + 2.4 * x2)   # Aprox 30
  y <- rBS13(n=n, mu=mu, sigma=sigma)
  data.frame(y=y, x1=x1, x2=x2)
}
