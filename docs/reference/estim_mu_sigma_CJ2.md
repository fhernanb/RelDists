# initValuesCJ2

This function generates initial values for CJ2 distribution.

## Usage

``` r
estim_mu_sigma_CJ2(y)
```

## Arguments

- y:

  vector with the random sample

## Value

A two-length numeric vector with initial estimates for \\mu\\ and
\\sigma\\ parameters from CJ2 distribution (see
[`dCJ2`](http://fhernanb.github.io/RelDists/reference/dCJ2.md)).
