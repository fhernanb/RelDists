# initValuesFWE

This function generates initial values for FWE distribution.

## Usage

``` r
initValuesFWE(y)
```

## Arguments

- y:

  vector with the random sample

## Value

A two-length numeric vector with initial estimates for \\mu\\ and
\\sigma\\ parameters from FWE distribution (see
[`dFWE`](http://fhernanb.github.io/RelDists/reference/dFWE.md)).
